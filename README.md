# 🚀 Readme Builder

A modern, local-first tool to generate professional GitHub README files with typing animations, tech icons, and dynamic sections — all without relying on external services.

---

## 🖼 Preview

---

## ✨ Features

* 🧠 Generate README dynamically with structured sections
* ⌨️ Typing SVG animation generator (100% local)
* 🎨 Built-in tech stack icons (no CDN required)
* 🧩 Modular architecture (clean and scalable JS structure)
* 💻 Fully client-side (no backend needed)
* 🔒 Privacy-first: no external APIs or dependencies
* ⚡ Fast and lightweight

---

## 🛠 Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla)
* SVG (dynamic generation)

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Davibzf/readme-builder.git
```

### 2. Navigate to the project

```bash
cd readme-builder
```

### 3. Open in browser

Just open the `index.html` file:

```bash
start index.html
```

## 💡 Why this project?

Most README generators:

* Depend on external APIs
* Use third-party services (bad for privacy)
* Have limited customization

**Readme Builder is different:**

* ✅ Fully offline
* ✅ No external dependencies
* ✅ Full control over customization
* ✅ Faster and more secure
* ✅ Ideal for developers who want independence

## 🧠 Architecture Overview

The project follows a modular structure:

* `app.js` → main orchestration
* `state.js` → state management
* `markdown.js` → README generation logic
* `typing-svg.js` → SVG animation engine
* `utils.js` → helper functions

This separation improves:

* maintainability
* scalability
* readability

---

## ⚙️ Customization

You can easily:

* Add new icons → `/assets/icons`
* Modify templates → `markdown.js`
* Adjust animations → `typing-svg.js`
* Extend features → modular structure
