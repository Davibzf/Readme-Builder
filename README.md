# README Builder

Uma ferramenta web gratuita para criar READMEs personalizados para perfis do GitHub de forma rápida, visual e prática.

O projeto permite gerar um README completo direto no navegador, sem necessidade de cadastro, instalação ou configuração de API. A proposta é ajudar desenvolvedores a deixar seus perfis mais profissionais em poucos minutos.

## Demonstração

Acesse o projeto online:

[README Builder](https://readmebuilderv.vercel.app/)

## Sobre o projeto

O README Builder foi desenvolvido para facilitar a criação de READMEs de perfil no GitHub. Em vez de montar manualmente badges, animações, cards de estatísticas e seções visuais, o usuário pode preencher as informações em uma interface simples e gerar o arquivo `README.md` pronto para uso.

A ferramenta é ideal para estudantes, desenvolvedores iniciantes e profissionais que desejam melhorar a apresentação do seu perfil no GitHub.

## Funcionalidades

- Geração de README para perfil GitHub
- Preview visual do resultado
- Suporte a modo claro e escuro
- Typing SVG animado com frases personalizadas
- Mais de 125 ícones de tecnologias
- Wave header e footer personalizados
- Cards de GitHub Stats
- Cards de Streak
- Cards de linguagens mais usadas
- Snake animation para contribuições
- Download do arquivo `README.md`
- Interface simples e responsiva
- Geração feita diretamente no navegador

## Tecnologias utilizadas

- React
- TypeScript
- Vite
- CSS
- GitHub Readme Stats
- Shields.io
- Simple Icons

## Como usar

1. Acesse a aplicação.
2. Preencha as informações do seu perfil.
3. Escolha as seções que deseja adicionar.
4. Visualize o resultado no preview.
5. Baixe o arquivo `README.md`.
6. Adicione o arquivo ao repositório especial do seu perfil GitHub.
